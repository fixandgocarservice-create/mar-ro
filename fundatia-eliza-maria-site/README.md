# Proiect nou: Website Fundația Eliza-Maria Bălcanu

Acesta este un proiect separat de paginile MAR existente în repository.

## Rulare locală
Deschide `index.html` direct în browser sau servește folderul cu un server static.

Exemplu:
```bash
cd fundatia-eliza-maria-site
python3 -m http.server 4173
```
Apoi accesează `http://localhost:4173`.
